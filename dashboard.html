Search what is trending right now

Streamers

    
    

    
    
    
Use trending videos as a backup
When your streamers have nothing new, the bot picks what is popular for your topic right now. With an empty list it uses trending only. If the list is empty and this is OFF, the bot cannot be turned on. This works in every mode: turn it OFF to stay strictly on your list.

Visibility

    
    
    
0 = public from the start. To try it out first, enter a number of days: from the moment you save it, automatic posts are Private (YouTube) and "Only me" (TikTok) for that many days, then go public by themselves.

  

    
Live chat watching

  
Live mode: watch live streams only
ON = live streams only. OFF = videos and VODs only (the two never mix). ON: the bot records several live streams on your topic (YouTube and Twitch) at once and reads their chat. When chat explodes (WTF, OMG, no way...) it cuts that moment, makes the Short and posts it, using the same daily limit, time window and gap as everything else. Streamers from your list are watched first. Uses bandwidth and some disk while it records.

Quality check

  
✓ Prioritize quality over quantity
ON (recommended, default): only clearly strong moments are posted, and when none qualify the slot is skipped instead of posting an average clip, so you may post fewer than the daily maximum. OFF: decent moments are accepted too and the AI check is optional.

AI frame check before posting
ON: before a clip is cut, an AI looks at 3 frames of the moment and skips it unless it is clearly about your topic with something happening (not talking, a menu or a quiet scene). Whenever an AI writes the titles it also gets a one-line description of what is on screen, so titles match the real event, even with this switch off. Uses the same AI as the titles: Claude (signed in) or your own API key with a model that accepts images. Only 3 small frames of the clip are sent. If the AI cannot be reached the moment is used without this check.

About Clippy

    
Clippy finds the best moments in streams and videos, cuts them into vertical Shorts and posts them to YouTube and TikTok, all on your own PC.

    
Source code and updates: github.com/FrostyDog222/Clippy
Based on the MIT-licensed gtavi-claudecode project by Bodila51.

  
Start with Windows

    
Start Clippy when Windows starts
Only works while Autopilot is ON. When this PC starts and you sign in, Clippy starts by itself, hidden in the background (no window, no browser), so Autopilot keeps working after a restart. With Autopilot off, nothing starts. Turn this off here at any time.

    

  

    
Backup

    One file with your settings and what Clippy learned from your ratings, so a reinstall or a new PC does not start from zero. It never contains your sign-ins, API keys, videos or logs. After a restore, Autopilot and Auto-Post are OFF until you turn them on.
    
Download backup

  

    
Notifications

    
Show a Windows pop-up when something happens
A normal Windows notification when a run finishes or stops, and when a scheduled post is done or failed, so you do not have to watch the dashboard. Off by default. It stays on this PC: nothing is sent anywhere.

  

    
Updates

    
Update automatically
Checks GitHub every few hours and installs new versions while nothing is running. Only program files are replaced: your settings, keys, accounts, clips and history are never touched.
